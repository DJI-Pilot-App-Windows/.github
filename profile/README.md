## Overview
DJI Pilot for Windows is designed as a step-by-step companion for drone missions, from the first pre-flight check through to reviewing the flight log afterward. New pilots can lean on its guided checklists, while experienced operators use the same screens to move quickly through routine flights. The goal is to reduce the number of things a pilot has to remember by hand before, during, and after a flight.

## Features
- [ ] Guided pre-flight checklist before every takeoff
